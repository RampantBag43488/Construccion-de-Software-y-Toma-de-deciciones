Preguntas de CSS

1. Que ventajas ofrecen las variables CSS sobre los valores hardcodeados?

Las variables CSS permiten reutilizar valores como colores, fuentes o tamanos. Si se necesita cambiar algo, solo se modifica la variable y se actualiza en todo el sitio.

2. En que casos conviene declarar variables CSS fuera del selector :root?

Conviene hacerlo cuando una variable solo se usara en una seccion o componente especifico, por ejemplo una card, un tema especial o una parte concreta del sitio.

3. Como se pueden utilizar las variables CSS para implementar un sistema de temas como modo oscuro?

Se pueden declarar variables para colores principales, fondos y textos. Luego, al agregar una clase como dark al body, se cambian los valores de esas variables.

4. Que sucede cuando intentas usar una variable CSS que no ha sido declarada?

Si la variable no existe, el navegador ignora ese valor. Tambien se puede poner un valor alternativo usando var(--variable, valor).

5. Cual es la diferencia entre los enfoques mobile-first y desktop-first?

Mobile-first empieza disenando para pantallas pequenas y despues adapta a pantallas grandes. Desktop-first empieza con pantallas grandes y despues ajusta para moviles.

6. Que breakpoints son los mas comunes y por que?

Los mas comunes son alrededor de 600px para tablet, 768px para pantallas medianas, 1024px para laptop y 1280px para desktop. Se usan porque representan tamanos comunes de dispositivos.

7. Como afecta el viewport meta tag al diseno responsivo?

Permite que la pagina se adapte al ancho real del dispositivo. Sin esta etiqueta, el navegador puede mostrar la pagina como si fuera de escritorio aunque se vea en celular.

8. Que tecnicas ademas de media queries existen para crear disenos responsivos?

Se pueden usar unidades relativas como %, rem, em, vh y vw, Flexbox, CSS Grid, imagenes responsivas y funciones como min(), max() o clamp().

9. Como puedes identificar que regla CSS esta siendo aplicada cuando hay multiples selectores?

Se puede revisar en DevTools, en la pestana Elements o Styles. Ahi se ve que reglas estan activas, cuales fueron sobrescritas y de que archivo vienen.

10. Que informacion proporciona la pestana Computed en DevTools?

La pestana Computed muestra los estilos finales que realmente esta usando un elemento, despues de aplicar cascada, especificidad y herencia.

11. Como puedes simular diferentes dispositivos sin tener acceso fisico a ellos?

Se puede usar el modo responsive de DevTools del navegador, donde puedes elegir tamanos de pantalla, orientacion y algunos modelos de dispositivos.

12. En que situaciones es preferible usar Bootstrap sobre Tailwind CSS y viceversa?

Bootstrap conviene cuando se quiere avanzar rapido con componentes ya hechos. Tailwind conviene cuando se busca mayor control visual usando clases utilitarias.

13. Que significa que Tailwind sea utility-first?

Significa que se construye el diseno usando clases pequenas y especificas, como clases para margen, color, padding, tamano o alineacion.

14. Como afecta el uso de un framework CSS al tamano final del bundle?

Puede aumentar el tamano final si se incluye mucho CSS que no se usa. Algunos frameworks permiten eliminar estilos no utilizados para reducir el peso.

15. Es posible combinar multiples frameworks CSS en un mismo proyecto? Por que si o por que no?

Si es posible, pero no siempre conviene. Puede causar conflictos de estilos, clases repetidas y un proyecto mas pesado. Es mejor usar uno solo si cumple con lo necesario.
