Preguntas

1. ¿Por que es una buena practica usar JavaScript para checar que sean validos los inputs de las formas antes de enviar los datos al servidor?

Es una buena practica porque permite revisar los datos desde el navegador antes de enviarlos. Esto ayuda a que el usuario corrija errores rapidamente, por ejemplo si dejo un campo vacio, escribio mal un correo o puso una contrasena muy corta. Tambien evita enviar solicitudes innecesarias al servidor.

2. ¿Como puedes saltarte la seguridad de validaciones hechas con JavaScript?

Las validaciones hechas solo con JavaScript se pueden saltar desactivando JavaScript en el navegador, modificando el codigo desde las herramientas de desarrollador o enviando la solicitud directamente al servidor con datos alterados. Por eso no deben ser la unica capa de seguridad.

3. Si te puedes saltar la seguridad de las validaciones de JavaScript, entonces ¿por que la primera pregunta dice que es una buena practica?

Porque JavaScript mejora la experiencia del usuario y ayuda a detectar errores antes de enviar la informacion, pero no sustituye la validacion del servidor. Lo correcto es validar en el cliente con JavaScript para hacer la pagina mas comoda y tambien validar en el servidor para proteger realmente los datos y el sistema.

Investigacion adicional

Uso de la etiqueta a

La etiqueta <a> sirve para crear enlaces a paginas internas o externas. Si se usa normalmente, abre el enlace en la misma pestana: <a href="pagina.html">Ir</a>. Si se quiere abrir en una nueva pestana, se usa target="_blank".

Submit en form y button con JavaScript

Un boton submit dentro de un formulario envia los datos al servidor usando el atributo action y el metodo indicado, como GET o POST. En cambio, un button con JavaScript puede ejecutar una accion personalizada, como mostrar un mensaje, validar datos o cambiar contenido sin enviar el formulario directamente.

Ruta absoluta y ruta relativa

Una ruta absoluta incluye la dirección completa, por ejemplo https://www.ejemplo.com/index.html. Una ruta relativa depende de la ubicacion del archivo actual, por ejemplo index.html o ./imagenes/foto.jpg. Para enlaces internos del proyecto normalmente conviene usar rutas relativas, porque funcionan mejor si el proyecto se mueve de carpeta o servidor.
