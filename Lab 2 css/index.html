Preguntas de reflexión

¿Cual es la diferencia entre padding y margin?

El padding es el espacio interno entre el contenido y el borde de un elemento. El margin es el espacio externo que separa un elemento de otros elementos.

¿Por que se recomienda usar box-sizing: border-box?

Porque hace que el padding y el borde se incluyan dentro del tamano total del elemento. Esto ayuda a que sea más facil controlar el ancho y alto de las cajas.

¿Qué significa disenar con enfoque mobile-first?

Significa disenar primero pensando en pantallas pequenas, como celulares, y despues adaptar el diseno para tablets y computadoras usando media queries.

¿En que situaciones preferirias rem sobre px?

Preferiria usar rem para tamanos de letra y espacios, porque se adapta mejor al tamano base del documento y facilita crear diseños responsivos. Usaria px principalmente para bordes o sombras pequenas.
