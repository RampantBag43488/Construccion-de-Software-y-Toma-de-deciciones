Preguntas AJAX

1. Que importancia tiene AJAX en el desarrollo de RIA's?

AJAX es importante porque permite actualizar partes de una pagina sin recargarla completa. Esto hace que las aplicaciones web sean mas rapidas, dinamicas e interactivas.

2. Que implicaciones de seguridad tiene AJAX? Donde se deben hacer las validaciones?

AJAX puede enviar datos al servidor sin recargar la pagina, por eso es importante validar bien la informacion y proteger las rutas. Las validaciones generales pueden hacerse del lado del cliente, pero las validaciones de seguridad deben hacerse del lado del servidor.

3. Que es JSON?

JSON es un formato ligero para enviar y recibir datos. Se usa mucho en aplicaciones web porque permite representar informacion como objetos y arreglos de forma sencilla.
