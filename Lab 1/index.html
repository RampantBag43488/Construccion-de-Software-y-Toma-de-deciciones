Preguntas

1. ¿Cual es la diferencia entre Internet y la World Wide Web?

Internet es la red global que conecta computadoras, servidores y dispositivos en todo el mundo. La World Wide Web, es un servicio que funciona sobre Internet y permite acceder a páginas, documentos, imágenes, videos y otros recursos mediante navegadores web.

2. ¿Cuales son las partes de un URL?

Un URL puede incluir varias partes: el protocolo como https, el dominio como www.ejemplo.com, la ruta del recurso como /carpeta/pagina.html, parámetros de consulta como ?id=10, y un fragmento como seccion.

3. ¿Cual es el propósito de los métodos HTTP: GET, HEAD, POST, PUT, PATCH, DELETE?

Los metodos HTTP indican que accion se quiere realizar sobre un segmento. GET solicita datos, HEAD solicita una respuesta similar a GET pero sin el cuerpo, POST envia datos al servidor, PUT crea o reemplaza un recurso, PATCH modifica parcialmente un recurso y DELETE solicita eliminar un recurso.

4. ¿Que metodo HTTP se debe utilizar al enviar un formulario HTML, por ejemplo cuando ingresas tu usuario y contrasena en algun sitio? ¿Por que?

Se debe utilizar POST, porque permite enviar los datos dentro del cuerpo de la solicitud y no directamente en el URL. Esto es más adecuado para información sensible como usuarios, contraseñas o datos personales.

5. ¿Que metodo HTTP se utiliza cuando a traves de un navegador web se accede a una pagina a traves de un URL?

Normalmente se utiliza el metodo GET, porque el navegador esta solicitando obtener el contenido de una pagina o recurso web.

6. Un servidor web devuelve una respuesta HTTP con codigo 200. ¿Que significa esto? ¿Ocurrio algun error?

El codigo 200 OK significa que la solicitud fue exitosa. No ocurrio un error, el servidor pudo procesar la solicitud correctamente.

7. ¿Es responsabilidad del desarrollador corregir un sitio web si un usuario reporta que intento acceder al sitio y se encontro con un error 404? ¿Por que?

Depende del caso. Un error 404 Not Found significa que el recurso solicitado no fue encontrado. Puede ocurrir porque el usuario escribio mal el enlace, pero tambien puede pasar porque hay un enlace roto dentro del sitio. Si el error viene de un enlace incorrecto en el sitio, si es responsabilidad del desarrollador corregirlo.

8. ¿Es responsabilidad del desarrollador corregir un sitio web si un usuario reporta que intento acceder al sitio y se encontro con un error 500? ¿Por que?

Si, normalmente es responsabilidad del equipo de desarrollo o administracion del servidor revisarlo. Un error 500 Internal Server Error indica que ocurrio un problema interno en el servidor, como una falla de configuracion, error en el codigo o problema con permisos o recursos.

9. ¿Que significa que un atributo HTML5 este depreciado o desaprobado? Menciona algunos elementos de HTML 4 que en HTML5 esten desaprobados.

Que un atributo o elemento este depreciado significa que ya no se recomienda usarlo, aunque algunos navegadores todavia puedan reconocerlo por compatibilidad. En HTML5 se recomienda separar estructura y presentacion, por lo que elementos antiguos como <font>, <center>, <big>, <strike> y <tt> estan desaprobados.

10. ¿Que componentes de estructura y estilo tiene una tabla?

Una tabla puede tener elementos de estructura como <table>, <caption>, <thead>, <tbody>, <tfoot>, <tr>, <th> y <td>. Para el estilo se recomienda usar CSS, por ejemplo para definir bordes, colores, alineacion, espacios internos y tamanoo de columnas.

11. ¿Cuales son los principales controles de una forma HTML5?

Algunos controles principales son input de distintos tipos, como text, email, password, number, date, radio, checkbox y file, al igual que select, textarea, button, label, fieldset y legend.

12. Sobre el ciclo de vida y desarrollo de los sistemas de informacion: ¿Cual es el ciclo de vida de los sistemas de informacion? ¿Cual es el ciclo de desarrollo de sistemas de informacion?

El ciclo de vida de los sistemas de informacion se refiere a todas las etapas por las que pasa un sistema desde que surge la necesidad de crearlo hasta que se mantiene, mejora o reemplaza. Incluye la planeacion, analisis, disenio, implementacion, operacion, mantenimiento y eventual retiro.

El ciclo de desarrollo de sistemas de informacion se enfoca mas en el proceso de construir el sistema. Generalmente incluye analisis de requisitos, disenio, programacion, pruebas, implementacion y mantenimiento. En otras palabras el ciclo de vida ve la existencia completa del sistema, mientras que el ciclo de desarrollo se concentra en como se crea y evoluciona tecnicamente.
